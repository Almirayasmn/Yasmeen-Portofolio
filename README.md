# Yasmeen Almira Portfolio

Feminine editorial portfolio for Yasmeen Almira.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## First things to customize

1. Add your portrait at `public/images/profile/yasmeen.jpg`
2. Adjust colors in `tailwind.config.ts`
3. Update project data in `src/data/projects.ts`
4. Update experience in `src/data/experience.ts`
5. Replace LinkedIn/GitHub links in `src/components/home/Contact.tsx`
6. Replace the placeholder resume with `public/resume/resume.pdf`

The first version intentionally follows the editorial landing-page direction from the provided reference.
